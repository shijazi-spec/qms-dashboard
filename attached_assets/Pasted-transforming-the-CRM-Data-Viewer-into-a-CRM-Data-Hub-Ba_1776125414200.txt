transforming the CRM Data Viewer into a CRM Data Hub:

Backend (index.ts + duplicateRadarDatabase.ts):

New POST /api/crm/enrich endpoint -- accepts the page of CRM records and returns two things for each record:
Cluster info -- looks up each record's zoho_record_id in the duplicate_records table to find if it belongs to a duplicate cluster, returning the cluster ID, domain, company, confidence level/score, and total records in the cluster
Live quality score -- runs assessDataQuality on the raw CRM record fields to compute a 0-100 quality score with specific issue flags
lookupRecordsByZohoIds() -- batch lookup of Zoho record IDs against the synced duplicate records database
runLiveQualityCheck() -- runs data quality assessment in real-time on raw Zoho records (works even before the records are synced into the Duplicate Radar)

The flow is:

Page loads CRM data from Zoho (same as before)
Table renders immediately with raw data
An enrichment overlay appears: "Cross-referencing with Duplicate Radar..."
The /api/crm/enrich POST call runs in parallel -- looking up cluster membership + computing quality scores
Table re-renders with quality badges, cluster indicators, and hygiene warnings
Health bar updates with counts of clean/issue/junk/duplicate records
This turns the previously disconnected viewer into a practical cross-reference tool that bridges raw CRM data with the Duplicate Radar and Data Quality systems.
