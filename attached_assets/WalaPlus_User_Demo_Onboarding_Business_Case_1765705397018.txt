WalaPlus QMS – User Demo & Guided Onboarding Module
Business Case & Functional Specification
Version 1.0

------------------------------------------------------------
1. PURPOSE
------------------------------------------------------------
This document defines the requirements to build a User Demo & Guided Onboarding
module inside the WalaPlus Quality Management & Agentic AI System.

The goal is to:
- Ensure every new user understands how to use the system correctly.
- Reduce dependency on manual training and support.
- Standardize understanding across all Business Units (BUs).
- Enable self-service onboarding for ROI / NPV initiative submissions.
- Improve data quality and decision-making accuracy.

------------------------------------------------------------
2. TARGET USERS
------------------------------------------------------------
- New Business Unit users (Sales, Marketing, Finance, IT, HR, Marketplace, etc.)
- Quality team members (Managers, Specialists)
- Executives (View-only demo mode)
- External stakeholders (optional – limited demo)

------------------------------------------------------------
3. SCOPE OVERVIEW
------------------------------------------------------------
The module will include:

1. Introductory Video Demo
2. Step-by-Step Guided Walkthrough (In-App)
3. Contextual Help & Tooltips
4. Shareable Demo Link for BUs
5. ROI / NPV Submission Guidance Flow
6. Completion Tracking
7. Role-Based Demo Content
8. Agentic AI Assistance

------------------------------------------------------------
4. INTRODUCTORY VIDEO DEMO
------------------------------------------------------------

A. Behavior
- On first login, users see a full-screen modal with:
  - Title: “Welcome to WalaPlus Quality & Investment System”
  - Short explanation of system purpose
  - Embedded video player

B. Video Requirements
- Duration: 2–4 minutes
- Covers:
  - What the system is
  - Why it exists
  - What users are expected to do
  - How ROI / NPV initiatives are submitted
  - Role of Quality & AI

C. Controls
- Play / Pause
- Skip (allowed)
- “Start Guided Tour” button at the end

D. Re-watch Option
- Video accessible later from:
  - Help menu
  - Profile menu
  - “?” icon in header

------------------------------------------------------------
5. STEP-BY-STEP GUIDED WALKTHROUGH
------------------------------------------------------------

A. Guided Navigation Flow
After video (or if skipped), system launches a guided tour:

Step 1: Dashboard Overview
- Explain main KPIs, modules, and navigation

Step 2: Projects & Governance
- Show how quality projects are tracked
- Explain ownership and timelines

Step 3: ROI / NPV Calculator
- Explain what initiatives are
- How to submit a new initiative
- What information is required

Step 4: Event Logs
- Explain transparency and audit trail
- Why logs exist

Step 5: AI Assistance
- How Agentic AI helps validate inputs
- How recommendations are generated

Step 6: Submission & Review Flow
- What happens after submission
- Quality & Finance review process
- Decision outcomes

B. UX Requirements
- Highlight active UI elements
- Disable unrelated actions during tour
- “Next / Back / Exit Tour” controls

------------------------------------------------------------
6. CONTEXTUAL HELP & TOOLTIP SYSTEM
------------------------------------------------------------

- Each key field (especially ROI inputs) has:
  - Tooltip explaining:
    - What the field means
    - How to calculate it
    - Which department provides the data

- Tooltips must be:
  - Simple language
  - Non-financial jargon
  - Consistent across system

------------------------------------------------------------
7. SHAREABLE DEMO FOR BUSINESS UNITS
------------------------------------------------------------

A. Shareable Demo Link
- Generate a read-only demo link that can be shared with BUs.
- Purpose:
  - Allow BUs to explore system before submitting initiatives.
  - Reduce confusion and incomplete submissions.

B. Demo Mode Behavior
- No real data is saved.
- Uses sample/demo data.
- Clearly marked as “Demo Mode”.

C. Access
- Link can be shared via email or intranet.
- Optional expiration date.

------------------------------------------------------------
8. ROI / NPV SUBMISSION GUIDANCE FLOW
------------------------------------------------------------

A. Smart Submission Wizard
- When a BU clicks “Create New Initiative”:
  - System launches a guided wizard
  - Explains each section step-by-step

B. AI Assistance
- AI explains:
  - Why a field is required
  - What realistic values look like
  - Warns about missing or unrealistic inputs

C. Validation Before Submit
- Checklist:
  - All required fields filled
  - Confidence level selected
  - Dependencies identified

------------------------------------------------------------
9. COMPLETION TRACKING
------------------------------------------------------------

- Track:
  - Video watched (Yes/No)
  - Tour completed (Yes/No)
  - Last demo version seen

- Store onboarding status per user.
- Allow Admin / Quality Manager to view onboarding completion.

------------------------------------------------------------
10. ROLE-BASED DEMO CONTENT
------------------------------------------------------------

- BU Users:
  - Focus on ROI submission and basic navigation

- Quality Team:
  - Focus on governance, audits, AI insights

- Executives:
  - Focus on dashboards and decision outputs

------------------------------------------------------------
11. AGENTIC AI ROLE
------------------------------------------------------------

- AI acts as:
  - Onboarding assistant
  - Real-time guide
  - Data quality validator
  - ROI realism checker

- AI can answer:
  - “What should I put here?”
  - “Where do I get this data?”
  - “Is this number realistic?”

------------------------------------------------------------
12. TECHNICAL REQUIREMENTS
------------------------------------------------------------

- Ability to trigger demo on:
  - First login
  - Manual restart
- Support video hosting (internal or external)
- Store onboarding status in database
- Demo mode environment with mock data
- Role-based demo flow logic

------------------------------------------------------------
13. SUCCESS CRITERIA
------------------------------------------------------------

- Reduced back-and-forth with BUs
- Higher quality ROI submissions
- Faster initiative approvals
- Consistent understanding across departments
- Reduced training effort for Quality team
