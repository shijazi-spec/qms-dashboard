Task: Build Slack Automated Quality Notifications

The Slack App (WalaPlus QMS) is connected and the trigger is registered in src/mastra/index.ts. Now I need automated Slack notifications sent to a channel when quality events happen. Here's what to build:

1. Create a new file src/utils/slackNotifications.ts with a function sendSlackNotification(channel, message, blocks?) that:

Uses the @slack/web-api WebClient (already in dependencies)
Gets the bot token from SLACK_BOT_TOKEN environment variable
Sends rich formatted messages using Slack Block Kit (with colors, sections, fields)
Has specific functions for each event type:
sendAuditCompletedNotification(channel, auditResult) — sends a summary with overall score, records audited, issues found, dimension breakdown (People/Process/Governance scores)
sendNonconformanceNotification(channel, ncDetails) — sends an alert with severity counts (critical/major/minor), red color for critical
sendCAPARequiredNotification(channel, capaDetails) — sends a CAPA action required alert with NC title, severity, and suggested action
2. Add a SLACK_QMS_CHANNEL secret — I'll set it to the channel ID where notifications should go (e.g., #qms-alerts)

3. Integrate into the existing audit trigger functions in src/utils/auditTriggerDatabase.ts:

In fireAuditCompletedTrigger() — after creating the database notification (line ~206), call sendAuditCompletedNotification
In fireNonconformanceDetectedTrigger() — after creating the notification (line ~258), call sendNonconformanceNotification
In fireCAPARequiredTrigger() — after creating the notification (line ~295), call sendCAPARequiredNotification
Wrap each Slack call in try/catch so a Slack failure doesn't break the audit flow
4. Example message format for Audit Completed:

──────────────────────

6. Add SLACK_QMS_CHANNEL to Replit Secrets — Set to the channel ID where notifications should be sent
