Step 1 — Activate the COPC scorecard

Archives the currently-active scorecard, inserts (or updates) the COPC v2.0.0 row as the only active one. Idempotent.

Step 2 — Score all unevaluated calls

For every call_records row that has a transcript but no sdr_call_evaluations row, runs the SDR evaluator against the active scorecard. ~3 sec/call, ~$0.0005/call.

Step 2b — Backfill historical evaluations to COPC

Re-scores every existing evaluation whose scorecard_name doesn't match the active COPC scorecard. Preserves the original score in legacy_score_v1. ~3 sec/call, ~$0.0006/call. For 181 historical calls: ~10 min, ~$0.11.

Step 3 — Efficiency report

Read-only aggregation: coverage, score drift v1.5→v2, per-section scores, per-agent top 10, outliers. Run any time.

⚡ Apply all (1, 2, 3 in sequence)

Runs Step 1 → Step 2 → Step 3 back-to-back. ~10 min total for 199 calls. Each step pauses on failure with the full response in the output panel. Confirms once before starting.
