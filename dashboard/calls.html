Zoho Calls Activity Import

Pull call timestamps + lead/deal linkage from Zoho's Calls module

Note: Zoho stores call activity data (who called, when, duration, linked lead/deal) but NOT the audio recording itself. For audio, use Bulk Call Recordings Upload above. The value of this import is surfacing calls the SDR team logged in Zoho but never uploaded a recording for — i.e. visible coverage gaps.

Imports go into call_records with status=analyzed so the scorecard can run against the Zoho-stored Description text. Re-running is safe — calls upsert on call_id.
