# Publish failure: "image size is over the limit of 8 GiB"

The deployment build can succeed completely (`mastra build` green, deps
installed) and still fail at the image-packaging step with
`error: image size is over the limit of 8 GiB`. This is NOT a code or build
problem — the Repl layer (the entire workspace directory, including hidden
dirs) is snapshotted into the container image.

**Root cause found here:** `.config/chromium/Crash Reports` had accumulated
**4.4 GB** of crash dumps from months of headless Playwright/Chromium test
runs (HOME is the workspace, so Chromium's profile lives inside it). Total
workspace hit 7.6 GB.

**How to diagnose:** `getDeploymentBuild` on the failed build — the error is
the last log line after "Created Repl layer". Then
`du -sh --exclude=.git -- * .[!.]*` at workspace root; suspects are hidden
dirs: `.config/chromium` (crash dumps), `.cache/ms-playwright` (~640 MB
browsers), `.mastra/output` (~700 MB build artifact, regenerated by the deploy
build anyway), `.cache/typescript`.

**Fix:** `rm -rf ".config/chromium/Crash Reports"` (pure junk, regenerable) —
dropped workspace 7.6 GB → 2.9 GB.

**Prevention:** playwright.config.ts now passes
`--disable-crash-reporter --disable-breakpad` to the chromium project's
launchOptions. NOTE: this is NOT sufficient — dumps regrew to 826 MB in ~2
weeks anyway (other chromium launches, e.g. screenshot/browser tooling, still
write to the same profile). Periodically `rm -rf ".config/chromium/Crash
Reports"` before publishing, and re-run the `du` sweep — other caches regrow.

**Related:** deploy builds can also fail transiently at the "Installing
dependencies" step — log stalls ~9 min then dies with no error line (or shows
"connection lost"). That is platform-side; code is fine if a same-day build
succeeded. Fix = just retry the publish (worked every time so far).

**Why:** deployment image = workspace snapshot; anything on disk counts, even
caches never referenced by code.

**How to apply:** whenever publish fails after a successful build with an image
size error, audit hidden workspace dirs before touching code or config.
