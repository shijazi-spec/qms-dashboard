SOP — Call Evaluation Tab

Platform: WalaPlus Enterprise GRC & Quality  •  Page: qms-dashboard.replit.app/calls
Owner: Quality Management  •  Audience: Quality Managers, Team Leads, SDRs, Admins  •  Version: 1.0  •  Effective: 25 May 2026

1. Purpose

Evaluate SDR call performance using the AI-powered COPC v2 scorecard, capture coaching actions, and ensure CRM hygiene and PDPL compliance.

2. Access & Roles

RoleCapability
Admin, Head of Ops & QualityFull access + seed/edit scorecards, bulk delete, approve evaluations
Quality Manager, Team Lead, AI Specialist, GRC ManagerView calls, run analysis & evaluation, create coaching plans
SDR (agent)View own evaluations and coaching plans only

Open the platform → sidebar Quality → Call Evaluation.

3. Daily Workflow

Step 1 — Confirm pipeline health

  1. At the top of the page, check the Health Metrics strip:
    • Pipeline yield ≥ 95%
    • CRM linkage rate ≥ 90%
    • Failed analyses = 0
  2. If any value is red, open the Logs tab and escalate to Admin before evaluating.

Step 2 — Ingest calls

Calls arrive automatically from Zoho CRM and Google Drive. For ad-hoc evaluation:

  1. Click Bulk Upload → select MP3/WAV files (≤ 25 MB each).
  2. Or click Ingest from Zoho to pull the latest call logs.
  3. New rows appear with Status: Pending.

Step 3 — Filter the queue

  • Source: Five9 / Twilio / Mobile / Upload
  • Agent Email
  • Status: Pending → Processing → Analyzed → Failed
  • Lead ID (to evaluate calls for a specific deal)

Step 4 — Analyze a call

  1. Select the row(s).
  2. Click Analyze (single) or Bulk Rescore Selected (multiple).
  3. Status moves Processing → Analyzed (~1–3 min per call).

Step 5 — Evaluate against the scorecard

  1. Click the call row to open the split workspace.
  2. Right pane: review the AI transcript (speaker-segmented), call summary, sentiment, and AI insights.
  3. Left pane: COPC v2 runs automatically. Confirm:
    • Overall Score (0–100)
    • People (25%) — communication, tone, active listening
    • Process (35%) — objection handling, discovery, script adherence
    • Governance (40%) — CRM hygiene, mandatory disclosures, PDPL/data accuracy
  4. Read Top Strengths, Top Gaps, Critical Risks, and CRM linkage.

Step 6 — Manager approval

  1. Adjust any attribute pass/fail if the AI is wrong (justification required — saved to sdr_evaluation_reviews).
  2. Click Approve Evaluation. The score becomes the official record.

Step 7 — Coaching plan

A plan opens automatically when an agent fails the same attribute 3+ times in 14 days. To open it manually:

  1. Click Create Coaching Plan on any evaluated call.
  2. Fill in:
    • Manager observation note
    • SDR commitment
    • Micro-training topic(s) — from the suggested list
    • Follow-up date (default +7 days)
  3. Save. Status = pending_delivery. The SDR is notified by email.
  4. On the follow-up date, return and mark the plan delivered / closed.

Step 8 — Export & reporting

  • CSV/Excel: click Export (top-right) for the filtered list.
  • Infographic: click Generate Infographic for a shareable PNG/PDF (weekly QA packs).

4. Scorecard Administration (Admin / Head of Ops only)

  1. Expand the Scorecard Management panel (collapsed by default).
  2. Click Create Scorecard or Toggle Active Scorecard to switch which rubric is applied to new evaluations.
  3. To restore defaults, run Seed COPC v2 (admin route — confirms before overwriting).
  4. Weight changes apply to future evaluations only. Past scores are immutable unless Bulk Rescore is run.

6. Troubleshooting

SymptomAction
Status stuck on Processing > 10 minClick Analyze again; if it fails twice, check Logs.
Status = FailedOpen call → read reason. transcription_failed: re-upload audio. openai_quota: notify Admin.
Score looks wrong vs transcriptOpen evaluation → override the attribute → write justification → re-approve.
CRM linkage shows "Unmatched"Verify the call's Lead/Deal ID in Zoho exists and is not merged.
No new calls appearingCheck Zoho sync status on Duplicate Radar page (shared auth).

7. Compliance Notes

  • All transcripts are PII-redacted before storage (PDPL/GDPR).
  • Evaluation overrides are audit-logged with reviewer email + timestamp.
  • Coaching plans count toward the agent's quarterly performance file.
